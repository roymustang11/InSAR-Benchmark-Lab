# Documentation figures

Figures used by the README and the documentation. All are generated by
[`_generate.py`](_generate.py) and are reproducible from the repository
root:

```bash
python docs/figures/_generate.py
```

| File | What it shows |
| --- | --- |
| `workflow.png` | Pipeline diagram from data inputs to result artifacts. |
| `wrapped_phase_vs_displacement.png` | LOS displacement field and the corresponding wrapped interferometric phase under the Sentinel-1 wavelength. |
| `coherence_map.png` | Mean temporal coherence with the 0.3 / 0.5 / 0.7 contours used by the coherence mask. |
| `timeseries_insar_vs_gnss.png` | Co-located InSAR and GNSS LOS time series with a linear velocity fit. |
| `residual_variogram.png` | Empirical semivariogram with an exponential model and labelled nugget, sill, and range. |
| `los_geometry.png` | ENU-to-LOS projection convention. |
| `processor_intercomparison.png` | Per-station velocity bias across multiple processors. |

All figures are synthetic placeholders and are clearly labelled as
illustrative. Real-data figures are produced by experiments under
[`../../experiments/`](../../experiments/) and are stored next to the
experiment that generated them.
